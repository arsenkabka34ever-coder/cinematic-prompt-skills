# CLAUDE CODE MEMORY
# This skill library is for cinematic image generation prompts.

## How to use this repo
1. Read SKILL.md for the full index
2. Load relevant skills before generating prompts
3. Combine skills: core + structure/genre + utils + presets

## Default stack for any cinematic project
- skills/core/cinematic-light
- skills/core/character-lock
- skills/core/9grid

## Quick reference
- Portrait project: + utils/skin-realism + utils/portrait-rerender
- Battle scene: + genres/great-battle
- Wedding: + presets/bride OR presets/wedding-cinematic
- Product: + products/product-object-cinematic
- Style match: + utils/reference-style-match
