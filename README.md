# Cinematic Prompt Skill Library

A modular system of cinematic image generation prompts.
Built for use with Claude, Gemini, GPT-4o, Midjourney, and Stable Diffusion.

## Structure
- skills/core — universal cinematic rules (load always)
- skills/structure — project frameworks (storyboard, turnaround, narrative)
- skills/utils — reusable utilities (skin, pose, rerender, identity)
- skills/genres — genre-specific visual DNA
- skills/presets — ready-made project packages
- skills/products — product visualization
- registry — token libraries and lighting presets

## Usage
Reference any skill in your prompt:
"Use skills: character-lock + cinematic-light + combat-kinetic"
